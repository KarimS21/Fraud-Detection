# Repositorio Reproducible - Evidencia Semana 14

Este repositorio debe permitir ejecutar el proyecto desde pasos documentados. La evidencia mínima esperada es:

- Notebook final con las semanas desarrolladas.
- Datos base o instrucciones claras para obtenerlos.
- Carpeta `data/` con artefactos procesados por semana.
- Carpeta `delivery/week14_final_integrated_delivery/` con documentos finales.
- Runbook con pasos de ejecución.
- Inventario de artefactos generados.
- Demo final con transacciones priorizadas y/o ranking de comercios.

Para defender el proyecto, no basta con mostrar diapositivas. Se debe abrir el repositorio, enseñar los archivos generados y explicar cómo se reproducen los resultados.
