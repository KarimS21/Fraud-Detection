# Datos para la demo visual

`sample_transactions_kaggle_format.csv` contiene filas sintéticas con las
columnas mínimas del esquema original de Kaggle que necesita el pipeline.

No contiene números de tarjeta, nombres ni direcciones. Los ejemplos son para
probar la interfaz y no representan casos reales ni resultados clínicos o
financieros.

La aplicación también acepta el archivo completo `data/raw/fraudTest.csv`.
Para una presentación rápida se recomienda cargar una muestra de algunas miles
de filas.
